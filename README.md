# Holly Eniola portfolio

- `css/style.css` — site styling and responsive case-study layout.

## Publishing
Upload the contents of this folder to the root of the existing GitHub repository, keeping the folder structure intact. `index.html` must remain at the repository root.

## Haven & Hue project note
Haven & Hue is a self-directed Shopify development-store demonstration. Product names, prices and imagery are illustrative; no supplier, inventory or live fulfilment arrangements are represented.
